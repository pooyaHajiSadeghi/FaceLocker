# Quick Start

1. Launch `FaceLocker.exe`, or run `scripts\run.bat` with Python 3.10 x64 installed.
2. Complete first-run setup with an internet connection.
3. Open **Admin**, enter an identity name, and register the first face. This identity becomes the administrator.
4. Open **Folders** and browse to add one or more folders. Adding a folder does not hide it.
5. Select rows. Use **Hide selected**, **Unhide selected**, or assign each row's **Next action** and apply selected choices.
6. Face the webcam in the right-hand panel. A fresh administrator check approves each batch.
7. Review the updated status and any per-folder errors.

**Stop / cancel** or Escape cancels verification. Cancellation, timeout, and rejection before approval leave visibility unchanged. Removing rows only removes them from the saved list.

To manage identities after initial enrollment, unlock **Admin** with the administrator's face. You can register or replace profiles, rename people, choose a different administrator, and delete non-owner profiles. Leave the Admin menu to relock it. Multiple enrolled identities can be recognized, but only the selected administrator approves protected actions.

Use the header control to switch light and dark themes. Camera settings are in **Settings**; after enrollment, changing the camera requires verification with the current camera.
